## 分析衔接演练

`tests/test_personality_full_grid_v3.py` 使用真实冻结输入网格、单独生成的确定性合成标签，在 pytest 临时目录内串联训练 frame 构造、训练内调参、参数导出、来源等权预测比较、八种评审面板、重复、角色干预、联合行为、信息机会探针和哨兵对照。没有读取真实语义标签，没有 API 调用，没有在研究目录写入预测锁。

该演练覆盖 1,280 个训练回答位置、4,040 个确认阶段回答位置及八事件的生产表结构，检查 30 个训练来源组和 32 个确认来源组分离。三个主要终点的四个嵌套预测器及风格竞争预测器均能拟合和评估；预先植入的模型默认信号和模型—学生状态交互信号被恢复。五项次要标签设为常量，用于检查相应数据表的边界处理。

演练只说明程序能够处理这些构造输入，不是模型人格的实证证据，也不能证明所有真实语义编码可靠。全仓 127 项测试随后通过。

## 零来源方差的解释规则

代码检查发现，冻结的配对 t 区间在所有来源差值为常量时会退化为零宽；主要预测检验已有保守的零方差不判显著规则，但中性措辞的数值等效标志仍可能为真。离散样本中观察到相同差值，不能据此推出未见来源总体的等效。

保留冻结主要分析及其原始数值标志，新增独立解释审计 `scripts/audit_personality_inference_edges_v3.py`。来源标准误绝对值不超过 1e-12 时，标记区间退化，不将该数值标志升级为总体等效结论。非退化区间仍依赖配对 t 和来源抽样近似，±0.10 的容许范围也不意味着严格相等。

该规则于 **06:45:31 UTC** 写入 `inference_edge_policy.json` 并记录脚本哈希，晚于测量试验和正式训练开始，早于确认生成。它是明确披露的确认前解释补充，不能冒称最初预注册。没有改变六项主要预测比较、已有数值输出或实验调用范围。

完整确认结果后需运行：

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/audit_personality_inference_edges_v3.py
```

现有冻结接续程序不会自动运行这个新增审计。最终撰写措辞等效结论时，必须同时查看其输出与 `paired_prompt_effects.csv`，不能只读取原始布尔列。
