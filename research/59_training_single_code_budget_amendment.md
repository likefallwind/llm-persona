# 单份训练编码的预算修订

2026-09-05。修订发生在训练编码开发之后、主要预测锁与任何确认回答之前；它不是原始冻结协议的一部分。

第一轮恢复结束后有 3,838／3,840 份结构有效编码。第二轮补回 DeepSeek 的 JSON 格式失败，最终有 3,839 份有效编码。唯一仍缺失的是 `7890f87b780f9df872d4:glm-5.3`：两轮中的四次调用均以 length 结束，16,384 completion tokens 几乎全部记为 reasoning tokens，没有可见答案。只读取用量和结束状态，未读取隐藏推理内容。

原控制器于 10:51:45 UTC 失败退出；确认控制器因训练未成功而退出。失败不是允许假定训练完成的理由，旧运行、审计和终态全部保留。

## 有界修订

- 只补这一份结构缺失的评审；筛选依据是完成失败，不读取行为标签或评审一致性。
- 相同请求模型、messages、量表、temperature=0；max_tokens 从 16,384 改为 32,768，timeout 从 360 秒改为 720 秒，单次额外运行最多两次尝试，无额外修复循环。
- 不重新生成任何导师回答，不替换原预算下的 3,839 份有效评审，不改来源划分、主要事件、预测方法或检验。
- 原预算组与扩展预算组分别交给原冻结审计程序，验证各自真实参数、payload 哈希、回答哈希、可见证据行、结束状态和完整编码。扩展预算不冒充原预算。
- 合并程序要求两组有效请求严格不重叠，且恰好覆盖原 3,840 项；逐事件必须保持三评审。多数与一致性算法保持原规则。
- 若扩展预算仍不能得到有效编码，则再次停止审查；不补零、不用另一评审代填、不删除题目。

实现与原始来源哈希在 `prospective_formal/training_budget_amendment.json` 中于调用前固定。产物置于 `training/budget_recovery/`。主要预测锁将固定合并摘要及其输入哈希；后续评审敏感性仍使用所有三方编码，并分别报告单评审、去 GLM 评审等结果。

## 解释与披露

增加完成预算可能改变可得到的评审输出，所以不能声称全部编码遵守原始统一预算。该修改发生于观察操作失败后、确认生成前，不声称是原始预注册。后续论文需明确交代受影响的单份训练编码、保留失败尝试、不同预算的实际调用与结果；多评审和去评审检查不能保证消除所有共同偏差。

这是完成编码的操作修订，不是已得到人格结论。独立确认、内容错误敏感性与论文最终结果仍未完成。
