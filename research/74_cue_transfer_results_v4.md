# 跨措辞结果：默认行动迁移，状态画像受表达方式限制

2026-09-08。5,120 个教师回答完成，15,359 条编码通过原严格解析，另 1 条经独立记录的单右花括号修复通过；15,360 条编码完整合并。没有新增修复 API 调用。三项主要事件的多数结果对该缺失编码取任意 0/1 都不变；两个次事件不满足这一不变性。详见 research/73 与 `json_recovery/missing_vote_bounds.json`。

## 主要结果

沿用 v3 训练得到的冻结预测，未重拟合任何参数。正值表示新增模型信息降低 Brier 误差。

| 新表达 | 比较 | 绝对误差改善 | 来源 bootstrap 95% CI | 六项 Holm p |
|---|---|---:|---|---:|
| 显式同义表达 | 给答案：默认模型 vs 情境 | 0.09730 | [0.08095, 0.11320] | 7.63e-11 |
| 显式同义表达 | 邀请推理：默认模型 vs 情境 | 0.13070 | [0.12266, 0.13825] | 4.97e-24 |
| 显式同义表达 | 承认情绪/困难：状态画像 vs 学科画像 | -0.00366 | [-0.00793, 0.00090] | 1.0 |
| 隐含线索 | 给答案：默认模型 vs 情境 | 0.08231 | [0.06657, 0.09695] | 2.76e-9 |
| 隐含线索 | 邀请推理：默认模型 vs 情境 | 0.12748 | [0.11660, 0.13806] | 8.51e-20 |
| 隐含线索 | 承认情绪/困难：状态画像 vs 学科画像 | -0.00628 | [-0.00960, -0.00273] | 1.0 |

单侧主要检验问的是“增益是否为正”。表中的 p=1.0 不是另行预注册的显著伤害检验；负向区间与配对退化估计给出了效应方向和不确定性。

同期 canonical 的状态画像改善为约 +0.01248；显式和隐含条件相对同期 canonical 的改善分别下降 0.01614（区间 [-0.02254, -0.00990]）和 0.01876（[-0.02384, -0.01358]）。因此不能把跨表达失效简单归因于所有部署随时间一起失效。逐个编码者分析均出现 canonical 正、新显式负、新隐含负的方向；逐一删除生成模型后，两个新表达条件的状态增益点估计也均为负，部分区间跨零。

这并不意味着模型不响应隐含情绪。所有模型在新表达的两极下都有较大的承认率差异；失效的是从旧固定措辞学到的模型条件画像直接迁移到这些新输入后的预测增量。新隐含表达还改变了继续学习的意愿、动作和时间等信息，不能据此声称已隔离出纯粹的潜在人格机制。

## 他人情绪对照的解释

保持当前学生明确 calm，只改变做另一题的同学的引语，承认当前学生情绪/困难的事件率变化依模型而异：M2.7 +30.47、M3 +25.00、DeepSeek +26.56、GLM +23.44、Doubao-lite -4.69 个百分点。前四个来源 bootstrap 区间为正，Doubao 区间跨零；这些是预先规定的次要描述性对照，不额外冒充主要多重检验。

不能把这一结果直接称作情绪归属错误。按固定哈希抽取每个模型一个 0→1 的对照实例，M2.7、M3、DeepSeek 和 GLM 的回答都可通过明确肯定“你很平静”形成阳性，且有回答明确区分同学的挫折属于另一题。这说明即使事实归属正确，社会上下文也可能改变模型是否回应同一学生状态。所抽实例仅用于解释，不是代表性错误率审计。Doubao 实例还显示“学习困难承认”与对同学的建议可能交织，应保留测量语义边界。

## 对论文结论的实际改变

v3 的“模型状态响应模式在新问题上有预测价值”仍是其固定措辞下的有效结果；但现在必须紧接着说明，这个状态画像未跨新的表达方式保持预测增益。答案提供和推理邀请的默认差异则跨表达保留。

新主线应是：**教育人格需要分层检验。模型的默认行动倾向可以复现并迁移，但把这些差异提升为稳定的学生状态响应规律，需要更强的证据；跨新问题成功并不保证跨学生表达成功。**

这比声称“有没有人格”更可证伪，但仍不是宣布顶会质量完成。自然对话和强教学指令下的档案验证尚未完成；四个固定新表达对、嵌套材料安排、仅 32 个复用确认题和 agent 编码的局限不消失。不宣称情绪理解、心理人格、教育独有性或学习收益。
