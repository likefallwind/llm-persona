# 第一篇整合论文：研究方向、结构与写作约定

2026-09-09。依据本任务当日完整讨论落实。此前目录中的稿件都是同一研究的中间版本，不作为本文之前的已发表工作。本记录承接 research/90–91，并以本轮用户确认的范围取代其中将 Harness 搭配作为主要后续目标的叙述。

## 确定的研究方向

研究从同题回答的性格印象出发，发现某些方面有重复性、另一些方面依赖情境，进而检验变化的条件与明确提示的作用。教育人格指教育场景中的特征性行为倾向，不要求人类心理人格构念，也不把任何偶然差异都算作性格。

研究过程：同题差异 → 特征筛查 → 稳定性与不稳定性 → 输入变化和调控 → 对教育行为的认识 → 配置推论。

当前实验足以用于撰写这一有范围的论文，不新增 API 实验或人工标注。学习收益不属于本轮研究。只有发现必要核心结论无证据或有实质分析错误时，才重新判断具体缺口；不能为了更丰富而无边界追加实验。

## 论文结构

1. 引言：同题回答差异、人格问题、从不稳定性引出的检验、三个研究问题。
2. 相关工作：人格测量、情境行为和导师行为；说明具体增量。
3. 数据、测量与实验设计：不同面板与证据身份；稳定性的多个估计目标；前瞻锁定、扰动与干预。
4. 哪些教学习惯区分模型：分为帮助行为中的重复差异、其他范围较窄的重复差异、共同表现与未确立的差异。帮助直接性只是首块的互补语义证据，不能代替全部发现；亲和作为测量依赖的例子，不能整体归为无差异。具体迁移检验留在第五节，ASK/EXPLAIN比较留在第六节。
5. 哪些差异跨变化保留：重复请求、新来源、学生表达、中性措辞；明确预测保留与概率／排序等效的区别。
6. 明确指令怎样改变差异：恢复三个小节，分别讲指定动作趋同与其他行为差异、默认排序在教学指令下可能改变、行为特征不能自动跨指令迁移。量级比较和评分边界调整仅作排序变化的支持，模型识别与详细数字留在附录。历史语义分析保持事后补充证据身份。
7. 讨论与教育启示：收拢为三点——可预测的教学倾向支持有依据的行为预期；指令控制不能代表完整回应均符合教学要求；行为评测为 AI 教育开发者针对模型配置和验证 Harness 提供依据。前两点解释实证发现，第三点为设计推论；指令后仍有差异不等于原有风格保持不变。
8. 局限：三点分别是场景与部署覆盖、自动行为测量、更多教学倾向有待检验。第二点区分主要行为编码与内容错误审核；第三点说明其他候选倾向及其关系仍需系统测试，不预设它们必然构成稳定性格。证据等级、研究时序、历史档案缺失编码及原门槛失败继续在方法、结果和附录披露。
9. 结论：具体发现和教育认识，末尾简述待验证配置推论。

## 写作边界

- “首阶段”“随后扩展”可以指实验先后，不得写成我们已发表的前文或另一篇工作。
- 稳定性必须写明：重复、跨任务排序、留出预测或绝对概率等效；不能混用。
- 语义引导量表与二元推理邀请不是同一个测量。后者的成功不撤销前者失败。
- 帮助直接性通过的是部分结果知情后固定的判定规则，不追溯为完整预注册。
- 各历史部署保持原名称，不把 GLM-5.2 当成 GLM-5.3，亦不混同 Doubao-Pro 与 Lite。
- 亲和试验可以支持有限跨教育／非教育情境的行为稳定，不能推广为 Big Five 或教育独有机制。
- 讨论主体是如何认识模型的教育行为。Harness只占最后一项推论，不能用其收益替代主要研究问题。
- 简单配置的预测同时要求目标适合和相关条件下可靠，不能将“稳定→直接可用”“不稳定→Harness一定有效”当作已证因果规则。
- 两阶段路由使用既有教师动作参考；不新增人工标注不等于所有补充实验均无人类来源参照。
- 保留两份缺失档案编码和原完整门槛失败；已识别多数不等于补齐编码。
- 稿件生成、数值审核与科学质量判断分开；不以构建通过宣称顶会录用或质量认证。
