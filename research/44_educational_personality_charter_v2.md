# 教育人格研究章程 v2

日期：2026-09-05。状态：用户已确认的研究方向；探索与设计阶段，尚非预注册确认协议。

本章程承接用户的明确决定：研究初衷是不同大模型是否具有不同的人格；当前证据主要来自教育语境，因此本篇集中研究**教育人格**。其他应用研究之后再做。research/00 的旧章程、旧实验门槛与原稿保留为历史记录；新工作以本章程为入口。

## 1. 唯一的核心问题

> 不同语言模型是否表现出稳定、可区分、能够跨教育情境预测其行为的教育人格？如果存在，它体现在哪些倾向及情境响应规律中？

这里的“教育人格”是待验证的行为构念：**同一部署配置在教育互动中反复表现出的行为倾向，以及随情境变化而重复出现的行为模式。** 不预设 Big Five/MBTI 结构，也不预设最终一定能找到人格。

模型能被语言指纹识别，不自动构成人格；同样，模型随情境或指令改变，也不自动排除人格。我们需要检验变化是否有可重复的结构，以及这种结构能否解释和预测新的教育行为。

若证据通过，可以明确表述“这些部署配置表现出不同的教育行为人格”，同时说明构念定义与覆盖范围。若只支持少量特定倾向，就按维度报告。若不能迁移，则报告人格假设的边界。教育领域结果不直接外推到通用人格或人的内在心理结构。

## 2. 三个研究问题怎样共同回答人格问题

| 研究问题 | 对人格命题的意义 | 需要的证据 |
|---|---|---|
| RQ1：相同教育情境下，模型是否具有可重复的默认倾向和情境响应差异？ | 检验模型差异是否超出随机波动、测量误差和任务差异 | 同输入跨模型比较；独立重复生成子样本；模型主效应与模型×情境交互分别估计 |
| RQ2：这些倾向能否预测新教育情境中的行为？ | 检验人格画像是否具有超出事后描述的稳定性和预测意义 | 源问题/对话分组；留出来源；与情境、总体均值、任务类别、风格和能力基线比较 |
| RQ3：教育人格在提示词干预下怎样保持或改变？ | 刻画人格的可塑性和条件，而不是另起提示工程论文 | 无关措辞扰动、明确政策指令、有关情境变化分开；比较默认倾向及情境响应曲线 |

RQ2 的目标是预测模型将怎样行动，而非预测学生成绩。RQ3 中“可被改变”不是人格存在的必要条件；“不容易改变”也不是充分条件。高质量教学、动作最优性和学习收益不作为本篇人格构念成立的必要门槛。

## 3. 如何形成有教育意义的维度

先依据教育互动中的可观察选择提出候选维度，再检验数据是否支持。下面是工作候选，尚不是已经确认的多维人格结构：

| 候选倾向 | 可观察行为 | 容易混淆的解释 |
|---|---|---|
| 帮助分配 | 直接讲解、给提示、追问、揭示答案的比例与条件 | 能力不足、强制格式、角色指令 |
| 教学主导 | 主动规定下一步、提供选项、给学习者决定空间 | 指令服从、篇幅、祈使句风格 |
| 互动支持 | 对困难或错误的承接、鼓励、共同推进 | 套话、礼貌词和表面温暖 |
| 认识立场 | 表达确定性、承认信息不足、保留判断、根据证据修正 | 知识准确率、概率格式、拒绝策略 |

不把“善于个性化”“教学效果好”直接当性格维度。相同倾向可能在不同情境产生不同后果。认知负荷、格式、长度可以作为行为特征或竞争解释，是否构成人格维度取决于独立证据。

每个维度分别报告：表达机会、编码一致性、重复生成一致性、总体倾向、条件性规律、跨来源预测、风格/能力区分。旧量表失效可以是测量或跨任务效度问题，不能不加区分地解释成该人格维度不存在；也不能换个名字就把旧失败当成成功。

## 4. 本篇范围

- 核心材料是模型在教育互动中的实际回答，不是让模型填写人格问卷。
- 先利用已有六模型核心和九模型扩展的配对输出；新增模型按可比覆盖使用。
- 自报告问卷、广义人格桥接、教学路由优化和学习效果试验不再扩展为主文分支。
- 通用任务可作为语言指纹与领域特异性的必要对照，不据此另开通用人格项目。
- 不新增人工标注。语义行为编码由盲化模型/agent完成；精确事件优先用程序或已有答案。多个评审一致不等于真值。
- 既有人类来源标签若使用，明确来源，作为可选的测量效标。人格的主证据不依赖“与某个人类动作一致”。
- 原始回答留在本地；新调用只补足已有数据无法解决的识别缺口。模型别名、日期、完整输入条件和采样参数分别记录。

因此，MRBench 的这 195 个去重对话全部包含于当前 BEA 开发集；BEA、MRBench 的不同名字不能提供彼此独立的确认来源。它们的模型提示并不相同，输入对话重复也不等于生成回答重复。

初始粗查曾将两个空题目字段的匹配计入标准/困难交集，得到 125；正式脚本排除空文本后的正确数为 **124**。标准集中 148 条、困难集中 62 条没有独立的 problem 字段，不能把空串当成共同题目，也不能因字段缺失就认定对话没有教学内容。

对现有语义面板的 239 个 context-arm 进一步追踪：224 个可映射到 210 个来源组，15 个仍因 problem 字段缺失而无法按题目归组。LongTutor 使用 learner ID 的哈希作为保守分组；其余使用原题文本哈希。标准/困难在已评分样本中共享 5 道题目，困难/Socratic 共享 2 道，标准/Socratic 共享 1 道。

上一轮二折预测使用局部 context ID，不能正确表达这些关系。其约 11.4%/6.1% 误差改善继续保留为探索结果，暂不升级为按原始题目独立验证的人格证据。

这些分组仍只识别规范化的完全匹配。改写题、同一对话的不同截断、历史适配器版本差异还需检查，未匹配不等于独立。当前产物是来源审计，不是已经冻结的确认数据划分。

## 6. 紧接着执行的证据链

1. **恢复来源与情境信息。** 优先处理已发现的15个语义面板未解析情境及跨集对话关系；构建不读取模型回答的情境标签。按来源问题/对话连通分组，保留完整配对臂，禁止跨训练测试泄漏。
2. **重新估计人格候选。** 在来源分组后的探索数据上比较统一画像和条件画像，同时加入任务与风格竞争基线。量化哪些稳定性来自共同提示，哪些来自模型差异；全部候选保留结果。
3. **独立验证画像。** 先审核既有但未参与画像形成的来源及模板。如没有可证明独立的材料，再用小规模新情境补充。预先冻结主要行为终点、测量方式、预测器和失败标准。
4. **验证可塑性。** 在相同情境中交叉变化无关措辞和明确教育指令，检查画像的保持、位移与条件变化；加入必要的重复生成来区分采样噪声。
5. **按证据重写论文。** 主文始终回答“有没有、是什么、在何种条件下稳定或变化”，教学适应性和路由结果只在直接支撑这个问题时引用。

方向对齐与来源审计后，已经完成来源分组后的预测、逐一去掉评审以及排除强制问题列表任务的敏感性分析，见 [后续证据评估](45_personality_evidence_gap_and_source_safe_results.md)。部分条件画像增益保留，但明显依赖任务集合，尚不能升级为独立确认的人格结论。正式阈值、独立确认数据与新干预仍待执行。
