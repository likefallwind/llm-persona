# 百万档案的角色覆盖与导师记录来源审计

日期：2026-09-05。只读既有档案；未增加模型调用、语义标签或人工标注。

## 角色覆盖：不能把教育任务名称当作导师身份

根据当前适配器的角色指令、任务描述和生成路径，逐一审查 census 中全部 39 个任务，保留每项的代码文件、类名、行号、文件哈希和解释。旧 `data/benchmark_roles.json` 不改写；其中未收录的新任务也不自动判为不可用。

| 当前任务角色 | 任务数 | 保留输入变体的去重记录 | 不区分变体的文本盘点 |
|---|---:|---:|---:|
| 评分／判断已有作答 | 7 | 354,308 | 354,308 |
| 考试解答／选项选择 | 10 | 306,307 | 305,709 |
| 混合教育辅助 | 2 | 78,322 | 59,413 |
| 导师回应 | 9 | 68,799 | 45,990 |
| 学习者历史查询／诊断 | 2 | 42,997 | 27,997 |
| 安全回应 | 2 | 13,974 | 9,969 |
| 自查／弃答／置信度解题 | 3 | 11,188 | 11,188 |
| 格式受限的问题列表生成 | 1 | 9,233 | 9,233 |
| 指定错误步骤修正 | 1 | 8,015 | 8,015 |
| 一般指令遵循 | 1 | 3,782 | 3,782 |
| 知识先修结构推理 | 1 | 2,100 | 2,100 |
| **合计** | **39** | **899,025** | **837,704** |

计数守恒已与原 census 核对。两种口径都是同任务—模型—题目—回答文本的盘点，**不是独立生成事件或来源情境数**。忽略变体的计数只描述文本规模，不能据此合并输入条件。

354,308 条评分输出与 306,307 条考试／选项输出合计占保留变体记录的 73.48%。这说明百万规模主要不能直接解释为导师人格样本；不意味着这些记录没有研究价值。

几个会影响论文解释的实例：

- Pedagogy Benchmark 实际是教学法知识选择题，当前 auto 模式还可能按模型选择提示变体；不是模型自主采取教学动作的记录。
- EduGuard SATA 虽包含教师角色和教育情境，最终要求从选项中选择并只输出字母；不能按开放回答直接编码温暖或推理邀请。
- ASAP、SAS 的被测模型分别是作文／短答案评分员；MRBench/BEA judge 的被测模型是在评价已有导师回应。评分所引用的导师文本不等于评分模型自己的教学行为。
- TutorBench 的三种用例分别要求解释、评估反馈和不给答案的提示，且包含图片输入；不能把用例差异直接当作默认人格差异。
- MMTutorBench 要求图片条件下的单步指导和固定三段结构，不能仅凭回答文本恢复完整输入。
- LongTutor teaching 本身要求利用历史、隐式诊断、不给完整答案；“默认”始终是指定任务与提示下的默认。
- EduBench 和 EduEquity 是混合教育辅助任务，应按题目任务和人群变体进一步分层，不应整块纳入或排除导师行为。

当前适配器是角色解释的代码依据，**不能证明每个历史请求都使用了当前代码**。本表是有依据的覆盖分类，尚不是所有历史输入协议的逐条复原。

## 对九类导师回应档案的实际逐文件核验

进一步读取九类导师回应的 122 个预测文件，共 573,297,890 字节。全部预测文件与对应摘要的哈希都与本日上午冻结 census 一致。按每文件最新成功模型—题目记录计，有 86,072 项；跨目录并保留变体的文本去重后，重现 68,799 项。

在这 86,072 项的已知顶层字段中：

| 可追溯信息 | 有记录的项目数 |
|---|---:|
| 完整 messages | 0 |
| prompt／text／input | 0 |
| 生成输入哈希 | 0 |
| provider／request ID | 0 |
| 返回模型身份 | 0 |
| 单次生成时间 | 0 |
| finish_reason | 0 |
| usage | 86,072 |

122 份对应摘要中，83 份有 generation_params，114 份有 judge_prompt_sha256，0 份有本审计识别的生成提示哈希。**评分提示哈希不是导师生成提示哈希**；摘要中有生成参数也不一定证明它属于原始生成而非后续重评分运行。

这个字段审计不证明其他日志或原始系统中不存在信息，也不意味着所有旧数据失效。它明确了还原路径：从原始来源、历史适配器、运行记录和迁移记录复原输入，分别记录哪些信息是原始保存、哪些是后来重建、哪些仍不可得。不能把后来重建的输入冒称成当时保存的请求。

standard 变体下，旧六模型共同题目 ID 候选覆盖包括 BEA tutor 300、MRBench tutor 200、LongTutor teaching 1,000、MathTutorBench 标准两臂各 1,150、hard 两臂各 327。它们仍需跨臂和跨数据集按原题／对话归组；ID 交集不证明协议相同。TutorBench 与 MMTutorBench 当前覆盖不足旧六模型交集，缺失不能靠插补制造。

## 对论文主线的影响

大档案继续承担发现候选规律、识别表达机会和暴露混杂的作用。不能把 1,028,822 条原始行写成百万独立导师回答，更不能写成百万条经过语义人格标注的样本。新实验的价值之一是保存历史档案缺少的生成输入、返回身份、参数、来源分界和预测时间关系。

当前角色表也表明仍有可利用的真实导师与混合教育材料。后续档案扩展优先恢复这些材料的来源与输入关系，而不是将所有原始行统一送给评审。已经看过或无法证明未用于探索的旧材料继续归探索，不替代正在执行的新来源确认。
