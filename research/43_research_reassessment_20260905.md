# 模型人格研究重新评估（2026-09-05）

本轮结论：**保留已有数据、代码和实验记录，重新组织核心研究设计与论文。** 原稿应作为旧研究快照保留。当前证据有价值，但还不足以支持“已经形成一篇有突出贡献的顶会论文”的判断；排版、测试、claim 数字核对通过也不能替代这个判断。

用户目标是理解不同模型在不同情境中的输出规律，不新增人工标注。本评估以此为研究范围。真实学生试验不是这个问题的必要前提；只有另行主张学习收益时才需要相应结果证据。

本轮完成了英文投稿稿的审读、research/00–42 实验链与结论的梳理、关键原始分析代码和结果表核对、当前预测目录的完整本地扫描、一个条件性行为结构的探索检验，以及邻近一手文献检索。没有逐条人工阅读百万回答，没有重新执行全部历史 API 实验，也没有将本次探索伪装成独立确认。原有论文和冻结分析产物保持原样。

## 1. 为什么需要重构

现有标题是 *Steering Is Not Personalization: Stable Behavioral Differences and the Adaptation Gap in AI Tutors*。正文提出六个研究问题，依次包含默认差异、跨任务稳定性、一般作者指纹、提示干预、模型响应异质性、教学适切性；随后又加入置信度、一般人格桥接、亲和性和两阶段动作路由。

这些实验各有动机，但共同占据了三个不同的论文中心：

1. 模型行为的测量及稳定性；
2. 教学指令对模型的控制和异质性；
3. 教学适应性及动作选择失败。

目前最突出的标题和结论属于第三项，用户最关心的问题属于第一项。进一步加实验或增强措辞不能自动解决这种错位。建议正文集中回答：

> **同样的情境下，不同模型如何行动；这些差异随情境变化的规律，能否预测未参与建模的输出？**

默认差异和提示响应进入同一研究对象；教学路由作为一个应用边界，亲和性问卷、广义人格量表映射和学习收益规划移出主线。

这不是先确定一个更“好看”的结论再找证据。可能得到的结论包括：存在可迁移的条件性行为规律；只能识别局部任务习惯；或者只有表层语言指纹可以稳定预测。三种结果都必须允许。

本轮脚本 `scripts/audit_archive_coverage.py` 递归读取当前 `reports/eval`。扫描排除路径中以 `_` 开头的历史、基线等目录；保留行级失败记录以统计质量。只读取原始文件，输出聚合计数及文件哈希。

| 当前本地快照 | 数量 | 含义 |
|---|---:|---|
| 所有 predictions.jsonl | 471 | 包括排除目录 |
| 纳入扫描的预测文件 | 425 | 6.602 GB |
| 原始非空行 | 1,028,822 | 包括重复、失败等，不能当独立样本 |
| 每文件保留最后一条后成功的模型–题目记录 | 967,607 | 尚有跨目录重复 |

| 不区分 input_variant 的同任务–模型–题目–回答文本去重记录 | 837,704 | 仅用于文本规模盘点，不据此合并实验条件 |
| 有成功输出的模型名称 | 22 | 覆盖极不均衡，不代表 22 个完整或独立家族 |
| summary 明记 complete 的预测文件 | 227 | 另有 193 个未记状态、5 个记为 running |

这里的 837,704 是**按任务、模型、题目和回答原文哈希定义的去重记录数**，不是全球唯一字符串数，也不是独立生成调用数。相同文本可能是目录复制，也可能是独立生成碰巧一致。没有来源事件 ID 时不能断言是哪一种。summary 的 running 是记录状态，本轮没有据此判断任务是否仍在运行。

六个核心模型按上述跨目录文本口径分别有：MiniMax-M3 113,575；GLM-5.2 93,030；Doubao-Seed-2.0-Pro 87,971；MiniMax-M2.7 85,471；DeepSeek-V4-Pro 82,076；Qwen3.5-4B 69,071。每个模型都有大量数据，但“每个十几万”并不适用于当前所有模型的去重成功输出。

旧清单日期为 2026-08-19，六模型交集是 47,321 个 benchmark-item、283,926 个回答。旧分析不是只看了几千条：核心教学透明特征覆盖 31,638 个回答，一般人格桥接的词典筛查覆盖 123,468 个自由表达回答。不过主要八维语义结论依赖 2,148 个回答；后来的四评审正式面板有自己的样本与重复关系，不能简单相加。

本轮发现的基础设施问题：

- 旧 `build_corpus_inventory.py` 只读 `benchmark/model/predictions.jsonl`。现在 208/425 个预测文件处于 `benchmark/judge/model/`，直接重跑旧程序会漏掉它们。
- 旧清单 238 个选中路径有 84 个不再存在；这首先是路径迁移/来源解析问题，不是数据丢失的证明。
- 忽略 input_variant 元数据差异时，当前六模型共有 54,023 个题目 ID，分布于 31 个任务。保持已记录 variant 分层时，共有 12,051 个 ID。这种差距说明元数据一致化是前置工作；两者均不能直接宣称是已验证的正式配对样本。
- “判分者输出”可以研究判分行为，“解题者输出”可以研究认识与修正行为，但不能混成“导师行为”。格式受限任务对某些行为没有表达机会，应记为不适用，不能打人格零分。
- 缺失 summary 状态不代表已有生成数据不可用；它意味着必须补查逐条成功状态、评分状态和历史 provenance。反过来，complete 也不自动证明协议可比。

因此，下一步应构建**生成事件与评分事件分开的统一清单**，恢复题目、来源问题/对话、完整输入条件和回答版本的关系。不要先把百万行全发给 judge。

| 17–22：因子提示、顺序复现、检测器审计 | 保留 question-first 和特定答案字段的操作性控制结果；鼓励词表失败保留。新论文中作为干预证据或附录。 |

| 41–42：五模型亲和性试验 | 保留为探索性补充；12 个情境、单一无关扰动及与 warmth 的重叠不足以支撑主文的广义人格结论。 |

目前最稳妥的旧结论仍然是：帮助直接性通过原有完整判定链；认知负荷具有较窄的跨任务签名证据；共享教学提示带来强平均位移且保留模型异质性。多数其他维度不能按原标准称为稳定跨任务倾向。

但“只有一个维度通过旧门槛”不等于“其余维度没有值得研究的稳定规律”。尤其不能把跨情境排序变化本身既当待解释现象，又直接当作排除所有行为规律的理由。

## 4. 当前稿件需要修正的实质性问题

### 4.1 标签来源写错

`paper/submission/main.tex:552` 写检测器对照的是 `human labels`。实际 `research/21_factorial_detector_validation_protocol.md` 指定 MiniMax-M3、GLM-5.2、DeepSeek-V4-Pro，`research/22_factorial_detector_validation_results.md` 使用三个 LLM 的多数标签。

应改为 “majority labels from three blinded LLM judges”。MathDial 的既有人类动作、MathTutorBench 的专家偏好是另外的标签来源，不能混写。无需为了改正措辞去新增人工标注。

### 4.2 平均效应被写成所有情境的效应

`paper/submission/main.tex:469` 的 `every learner context is pushed in the same direction` 不成立。本轮从已发布三评审共识表逐项重算：

| 维度 | 增加 | 不变 | 减少 | 配对模型–情境数 |
|---|---:|---:|---:|---:|
| 直接帮助 | 42 | 147 | 525 | 714 |
| 提问/引导 | 567 | 122 | 25 | 714 |
| 认知负荷 | 63 | 230 | 421 | 714 |

可以说“各模型的平均效应方向一致”，不能说“所有情境同方向”。这也意味着旧稿对局部变化的刻画不足。

### 4.3 人类下一步动作不是唯一正确动作

`paper/submission/main.tex:523` 的 `consistently wrong for the local teaching decision` 超出终点。实验测的是与某个已观察教师动作的匹配，动作分类器的 macro F1 约 0.56；另一种动作可能也合理。应写“降低 telling 目标情境中的动作匹配”。近 0.50 的二元选择匹配也不能推出模型普遍不会根据情境选择策略。

### 4.4 特定预测失败不能推出没有学习者理解

LongTutor 的加入特征后 AUC 下降是特定数据、目标和预测器下的增量效度失败。它约束“这些教学评分能预测诊断”的命题，不能排除模型内部使用学习者信息。未达到效果门槛也不等于通过了零效应或等效性检验。

### 4.5 量表门槛混合了不同问题

旧 `reliable_semantic_measurement` 把评审可靠性、量尺范围、提示效应不反转放在同一合取条件里。评审一致性与提示效应方向不是同一性质。真实的模型×情境/指令交互也可能造成反转。

新框架应分别报告：测量可靠性、表达机会、默认差异、条件性变化、预测泛化、与能力/表层风格的区别。保留旧决定，不事后降低旧阈值，也不把“未通过旧决定”泛化成普遍不存在。

### 4.6 有些构念拒绝措辞同样过强

组织格式与 IFEval 准确率的六模型负相关不足以单独“证伪尽责性”：能力、任务和代理指标都可能影响结果。准确说法是“此组织格式代理未建立尽责性效度”。同理，无法从档案识别某个 HEXACO/Big Five 构念，应记为未测得或不可识别。

### 4.7 重复评分、重复生成、跨时间稳定性不能互换

多个 judge 对一个回答一致，证明的是评分的一致性；同一模型在一题上的独立生成是否重复，仍需相应采样。模型版本、日期、提示和采样参数未完整留存，也限制了跨时间与家族因果结论。先做固定部署配置内的比较是合理的，不必为了听起来像总体心理测量而设置任意模型数门槛。

## 5. 本轮新做的探索：条件性差异是否有可预测结构

这是事后探索，不能升级任何历史 trait 决定。

从旧三评审表取 generic MathDial 标准/困难、LongTutor、Socratic 四个任务–提示设置，排除 pedagogy 配对臂，保留全部八维：239 个 context-arm、1,434 个模型回答、237 个分割组。标准和困难的两个相同 context ID 被放在同一组。尚未核对所有底层问题/对话血缘，因此这不是严格按源问题留出的确认集。

每条分数先减去同题六模型均值，评估的是模型间相对差异。比较两个只从训练半样本估计的预测器：

- **统一模型剖面**：每个模型一个分数，四任务等权。
- **任务条件剖面**：每个模型在各任务中有自己的分数。

100 次确定性分组二折，每次两半互换测试。报告任务等权的 MSE 改善；划分百分位仅为敏感性范围，不是置信区间，100 次划分不是 100 个独立实验。

| 维度 | 任务条件剖面相对统一剖面的平均误差降低 | 改善的划分比例 |
|---|---:|---:|
| personalization 评分 | 12.16% | 99% |
| affective warmth 评分 | 11.71% | 100% |
| elicitation 评分 | 11.37% | 100% |
| autonomy support 评分 | 9.30% | 100% |
| help directness 评分 | 6.10% | 100% |
| diagnostic specificity 评分 | 4.52% | 96% |
| cognitive load 评分 | 2.62% | 93% |
| epistemic caution 评分 | -1.25% | 29% |

实现检查：已知相反任务剖面的合成正控得到约 96.8% 改善；在真实上下文内随机打乱模型身份、保留整条八维回答的单次负控中，八维全部恶化约 2.5%–4.4%。负控只是实现合理性检查，不是完整置换显著性检验。

**可得出的新判断**：部分被总体稳定性门槛排除的评分，仍含有在同一任务–提示设置内可重复估计的模型差异，值得进一步研究。

**尚不能得出的判断**：发现了条件性人格，warmth/personalization 得到了构念验证，或者能预测未知任务。任务与指令混杂、同一评审体系、候选并列评分、旧数据已被反复查看等解释仍存在。尤其 personalization 是原评分名称，不是已确认的个性化能力。

## 6. 创新空间需要重新定位

截至本轮一手来源检索：

| 研究 | 已覆盖的方向 | 对本项目的要求 |
|---|---|---|
| [TRAIT，NAACL Findings 2025](https://aclanthology.org/2025.findings-naacl.469/) | 约 8K 情境化多选人格题及模型差异 | 不把“比问卷多一些情境”当主要创新。 |
| [A psychometric framework，Nature Machine Intelligence](https://www.nature.com/articles/s42256-025-01115-6) | 多模型心理测量可靠性、效度和塑造 | 不以“做了很多 ICC 和相关”作为贡献核心。 |
| [Your LLM, Your Style，2026-08-11 预印本](https://arxiv.org/abs/2608.10703) | 3,200 个情境、20 种行为、四种交互形式；情境化行为差异及激活控制 | “行为优先”“模型特异性”“受情境影响”已有直接邻居。当前参考文献和研究文档尚未包含此文。 |
| [From Representations to Behaviors，2026-07-29 预印本](https://arxiv.org/abs/2607.26853) | 模型内部表示、情境表达、行为效应之间的联系 | 不声称首次提出模型–情境–行为框架。 |
| [LLM-Native Psychometric Instrument，25 模型研究](https://arxiv.org/abs/2606.09843) | 自报告和实际行为之间的间隙 | 五模型问卷–亲和性分离适合作补充，不足以单独承担创新。 |
| [Can LLMs Match Tutoring System Adaptivity?](https://arxiv.org/abs/2504.05570) | 75 个教学场景及学习者上下文消融 | “提示不等于适应”不是无人研究的问题。 |

上述对照基于本轮原文摘要、来源记录及 BMA 正文相关部分；不是系统综述，也不表示这些预印本已被顶会接受。来源内容不支持把原论文直接判定为“没有创新”，但足以推翻“行为分析加提示影响就自然足够新”的假设。

把行为看成条件分布有经典来源，例如 [Mischel、Shoda、Mendoza-Denton 的 situation–behavior profiles](https://journals.sagepub.com/doi/pdf/10.1111/1467-8721.00166)。这里借用可检验的行为规律视角，不把人类内部心理机制直接移植给模型。

我认为可争取的贡献是：**在任务自然要求下的大规模既有输出中，发现并验证可预测的条件性行为规律，量化总体分数遗漏了多少信息，以及这些规律能否跨来源、跨提示迁移。** 这是一条有竞争可能的路线，尚不是已证实的创新结果。

## 7. 不新增人工标注的研究设计

### 7.1 先规定可识别的行为，再选测量方法

优先候选是帮助分配（讲解、提示、追问、答案揭示）、认识表达（信息不足下回答或保留、置信度）、错误修正（原先正确/错误时改变什么）、边界处置（拒绝、部分回答、替代方案）。每项需有相应输入情境和表达机会。情绪标签、Big Five 和“同理心”不作为自动生成的目标真值。

不同角色分别建模，再测试可比事件能否迁移。有限选项的输出也可用于认识或修正行为，但不拿它评价温暖程度。

- 可精确判断的事件用结构解析、规则、执行结果或已有答案判定。
- 开放文本可由模型盲化地编码具体动作，并输出证据片段位置及无法判断状态；保留分歧，不把多数票称为真值。
- 先校准小样本的多个独立测量方法、逐回答/并列评分差异、长度/格式敏感性，再决定是否扩到大样本。
- 既有专家标签仅在适合的外部效标中使用，明确“未新增人工标注”和“完全不含人类来源标签”的区别。即使不用这些既有标签，预测未来输出规律的核心问题也可以成立。
- 不使用模型解释自己为什么回答作为内部心理或因果真值。

### 7.2 情境编码必须只看输入

候选变量包括任务角色、学科、题型、证据充分性、请求直接帮助或探索、已有正确/错误状态、历史长度、冲突约束。冻结情境分类器时隐藏候选模型及其回答，避免从回答反推情境造成循环。

“困难”优先用输入元数据或训练侧估计，不用被测试模型该题的结果反向定义。表层风格可作为竞争解释；长度也可能是干预产生的行为，因此不能机械地把它作为控制变量回归掉所有提示效应。

### 7.3 正文只回答三个问题

**RQ1：差异中有多少是稳定默认值，有多少是模型×情境交互？**

按固定部署配置、输入、指令、来源和评审记录组织数据。分别拟合仅情境、情境加模型主效应、模型×可解释情境特征模型。对二元行为用概率模型和 Brier/log loss，对有序评分用合适的有序模型并做量尺敏感性分析；先不强行拟合大五式潜在因子。

同题跨模型比较控制输入，来源问题/对话用于分组。单次生成残差不能拆成纯采样噪声和模型×具体题目效应；小规模重复生成只用于补这个识别缺口。

**RQ2：知道模型的条件性行为，能否预测没参与建模的输出？**

必须比较以下基线：仅情境、模型总体均值、表层风格/长度、模型×任务类别，以及模型×输入情境。若最后一种不能超过模型×任务类别，就只能说存在任务特定习惯，不能升级为可迁移情境规律。

分割强度逐步增加：同来源新问题/对话 → 留出完整来源 → 留出提示措辞或新的匹配情境。题目变体、相同原对话、generic/pedagogy 配对必须同组。最终确认材料不得参与维度、阈值、模型或文字模板的选择。

留出模型是另一个更强的问题：没有该模型的任何样本就无法估计其固定效应。若研究新模型，应明说使用少量校准输出后预测其他情境；不把这个问题混入当前六模型的跨情境预测。

**RQ3：提示词改变默认倾向，还是改变对情境的响应？**

把无关改写、角色/政策指令、真正与决策有关的情境变化分开；最好交叉操纵。比较同一模型的默认截距、情境斜率和交互，检验哪些 rank reversal 在独立情境中重复。用明确的正确答案、输入事实和解析事件作锚；设计本身不能把某一行为直接写成唯一合规格式再宣称发现深层性格。

这一步只有旧档案无法回答的最小部分需要新生成。旧 provider 别名与新部署不得混作同一个时间稳定样本；Doubao-2.0-Pro 与 2.1-Turbo 尤其分开。

### 7.4 大数据如何增加深度

大样本首先用于细分情境、估计行为概率及尾部例外、发现平均值掩盖的反转、留出完整来源验证、研究成功/失败与行为的条件关系。不要仅把六个模型均值的小数位变多。

不必让所有 22 个模型都参加所有测试。主结果在协议可比的配对交集上完成；扩展面板利用局部公共覆盖并报告缺失模式。层级模型不能自动消除缺失非随机和模型–任务混杂；不以插补制造从未观察过的模型行为。

## 8. 怎样处理“上下文污染”和重新开始

已有结果不需要删除。真正需要隔离的是**假设形成和假设检验**，而不是把仓库历史清空。

1. 现有论文及所有已查看结果统一归入 discovery/legacy 层，原冻结门槛和失败不改写。
2. 建立新的研究章程、可识别终点、唯一数据清单、来源级分割及终止规则。
3. 不能把旧分析看过的输出重新随机切一刀就称为“从未接触的确认集”。本轮二折检验就是探索。
4. 新增档案来源可以候选为确认材料，但必须审计是否被既往特征挖掘/选择使用、是否与旧源问题重叠。未能证明独立的材料仍归探索。
5. 如没有足够独立的既有材料，生成少量新的、模板与内容层面留出的情境；不必重生成百万条。
6. 后续另开会话可以只加载新章程、数据契约和冻结协议以减少叙事锚定，但新会话本身不能消除统计上的复用偏差。

因此建议采取“**复用证据底座，重开确认设计**”。当前会话已经看过旧结果，不应声称已实现完全盲化的新研究。

## 9. 面向顶会的写作形态和停止条件

建议工作标题：*Beyond Average Traits: Predicting Context-Dependent Behavior Across Language Models*。这是问题导向工作标题，不能在结果前预写获胜摘要。

正文结构：Introduction（一个核心问题）→ Data and Identification（数据单位、来源和配对）→ Behavioral Measurement（动作、机会、测量误差）→ 三个 RQ 的结果 → Discussion and Limitations。主图依次展示情境覆盖、平均值与条件曲线、来源留出预测、提示下的响应变化。

直接性、置信度和路由不再各自开启一个独立故事。它们只有在支持同一个可预测行为主张时才进入正文。Big Five/HEXACO 大范围映射、亲和性问卷、家族相关、学习试验规划放附录或后续独立研究。

研究执行阶段与交付：

| 阶段 | 必须交付 | 失败时的处置 |
|---|---|---|
| 数据契约 | 生成/评分事件分离；可比输入和源问题分组；各行为表达机会矩阵；探索/确认暴露账本 | 无法确定协议的记录保留为覆盖数据，不进主要因果/配对结论 |
| 测量校准 | 客观事件与语义编码的对应；评审/格式/并列评分敏感性；所有候选保留 | 无可靠测量的维度退出主文，不反复改词救分 |
| 档案建模 | 默认与条件模型的比较；局部反转；任务与风格竞争基线 | 若只在任务内成功，明确局部规律，不能声称跨来源 |
| 独立确认 | 固定预测器在隔离来源/新情境上优于冻结基线；来源聚类区间和适当多重校正 | 按协议报告不支持；不靠扩大同类样本补叙事 |
| 定向干预 | 区分无关扰动、有关情境和政策指令；保留重复生成及完整元数据 | 若不可识别或无效，限制结论到描述性预测 |
| 论文重写 | 一个核心贡献、三问、清晰证据边界；数字与原始文件可追溯 | 工程审计通过不作为科学成功替代品 |

确认前需要冻结主终点和有实际意义的最小改进，并由探索侧的测量噪声/功效确定；不能用本轮结果量身挑一个刚好通过的阈值。固定面板推断以问题/对话为簇，跨任务主张还需按来源报告；重复分割和重复 judge 不增加模型样本量。

如果独立来源上没有超越任务/风格基线的条件性预测优势，应诚实转向“行为画像迁移的边界”这篇测量论文。不能承诺顶会接受，也不应为了满足顶会愿望扩大结论。
