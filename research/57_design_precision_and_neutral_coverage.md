# 固定设计的精度与中性措辞区间覆盖诊断

日期：2026-09-05。训练评审仍在执行，确认回答尚未生成。全部数值来自预设概率模型的合成模拟，没有使用真实导师回答或行为标签，没有新增 API 调用或改变样本量。

## 为什么进一步检查

research/55 已处理零来源方差时的退化区间。但固定设计只有 16 个提示来源，每来源每臂四种学生状态、两次请求；即使方差不为零，少见行为也可能产生偏斜、离散的来源差值，使名义 t 区间低估不确定性。因此需要同时检查精度和覆盖，不能只记录区间是否退化。

`scripts/check_personality_design_precision_v3.py` 对 11 个明确给定的概率设置各运行 100,000 次模拟。各角色在同一来源和状态下独立生成 Bernoulli 事件；预设概率不由任何模型输出拟合。向量化区间与冻结 `paired_stats` 对照，模拟来源方差与解析方差核对，均通过。Monte Carlo 比率的区间只衡量模拟误差，不是教育总体区间。

## 观察到的设计限制

中性措辞比较的临界 t 值为 3.82197；即使观察到的平均差值恰好为零，来源差值标准差也必须小于 0.10466，名义区间才可能完全落在 ±0.10 内。

在真实差值为零的合成设置中，按旧非退化规则判等效的模拟比例为：

| 每次生成的预设事件概率 | 模拟判等效比例 |
|---|---:|
| 0.01 | 88.691% |
| 0.05 | 17.904% |
| 0.10 | 1.113% |
| 0.50 | 0.003% |

若四种状态概率交替为 0.05 与 0.95，平均发生率同样为 0.50，但模拟判等效比例为 18.015%。这说明总体发生率本身不足以判断精度，状态内的生成波动也很重要。全为零时区间退化，旧解释规则已经保守地不判总体等效。

更重要的是，在 canonical 概率为 0、neutral 概率为 0.10 的容许边界设置中，旧非退化规则仍有 **0.591%** 的模拟重复判等效，双侧区间不覆盖真实差值的比例为 **0.604%**，超过该单比较名义不覆盖率 0.1667%。这是非零方差情况下的覆盖反例。它不能用来估计真实模型的误判率或真实 30 个相关比较的家族错误率，但足以说明名义覆盖不能在这些少样本离散条件下得到保证。

另一个纯高斯来源差值演示给出：在 32 个来源和保守的 Holm 首步阈值下，80% 检验力对应的标准化均值差约 0.600；高斯模拟恢复到 79.966%。这是有明确分布假设的尺度说明，**不是实际 Brier 比较的检验力估计**，也不据此推算真实研究已经足够或不足。

## 保留冻结输出，补充有界来源检查

不改原六项主要预测检验或原 t 区间；原零方差审计也完整保留。新增 `scripts/audit_personality_neutral_bounds_v3.py`，对中性措辞结果增加有界来源区间，并把原始数值标志、非退化 t 标志、有界检查标志分别保存。

每个来源的事件率差位于 [-1,1]。在独立来源抽样近似下，依据 [Hoeffding 原论文定理 1 的式 (2.3)](https://www.cs.rpi.edu/academics/courses/spring06/random/hoefding.pdf) 缩放变量，并对双侧和 30 个比较使用联合界，半宽为：

`sqrt(2 * log(2 * 30 / 0.05) / n)`。

在 n=16 时半宽约 0.9414，远宽于 ±0.10。这项保守检查不能支持总体等效；未通过也不表示存在提示效应。正文仍可以描述这 16 个来源中实际观察到的位移，展示名义 t 区间及其限制，但不能把“小位移”或原布尔值升级为总体等效结论。该检查依然不能把 agent 编写的来源变成教育总体的代表性概率样本。

规则在看到旧档案、测量试验和本次合成诊断之后制定，时间早于确认生成；通过 `neutral_bounds_policy.json` 固定实现与诊断哈希。这是明确披露的解释补充，不冒称原始预注册，也没有通过改题、增样或更换主要终点来追求有利结果。

## 复现与最终使用

合成诊断及解析校验：

```bash

```

完整确认结果之后依次执行：

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/audit_personality_inference_edges_v3.py
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/audit_personality_neutral_bounds_v3.py

```

原接续进程不自动运行这两个独立解释审计。图表程序要求有界审计并验证对应输入哈希。最终叙述应使用 `confirmation_neutral_bounds/neutral_equivalence_interpretation.csv` 的综合标志，同时保留旧审计作为方法演进记录。
