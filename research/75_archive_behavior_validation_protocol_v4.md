# 自然对话档案验证方案 v4

2026-09-08。此方案在看过 v3 与 cue-transfer 结果后制定。它是已有档案上的外部情境验证，不宣称档案回答从未用于探索，也不冒称新生成的前瞻确认。目标是检验不同模型的行动画像在真实形式的多轮数学辅导对话和教学指令下的表现。

## 面板与纳入规则

从 research/72 恢复的 MathTutorBench standard scaffolding/pedagogy 配对条目中选择。两个任务都限制最多两句；前者要求 useful/caring 的数学老师，后者明确要求逐步引导、探问且每轮仅问一个问题。这里比较的是历史提示条件，不是未经指令干预的心理特质。

只纳入具有明确非空问题、非占位参考解、非空对话，且两个任务在同一索引处问题/对话/参考解完全一致的来源。七个档案配置均须在 standard 变体下恰有一个去重回答文本，并逐条核对冻结预测文件哈希、行号、model/item 和回答哈希。参考解是上游材料，未将其非空误当作正确性验证。缺失问题和占位参考不补造；不使用上游人类教学质量标签或 tutor gold 回答。

当前候选有 1,002 个对话条目、612 个完全匹配来源组。按 `archive-natural-v4:` 加 source_group 的固定 SHA-256 排序取前 256 组，再在每组按固定材料哈希选一个对话，两个指令臂使用同一对话。抽样只看输入和覆盖，不看回答语义、事件标签或模型优劣。不追加样本至显著。

面板为 256 来源 × 2 指令 × 7 档案配置 = 3,584 个已有教师回答；三位盲化 agent 编码者合计 10,752 次编码目标，不再生成教师回答。七配置为 MiniMax-M3、MiniMax-M2.7、GLM-5.2、DeepSeek-v4-pro、Doubao-seed-2.0-pro、Qwen3.5-4B、Qwen3.8-27B。这些是档案请求配置，没有逐请求返回权重身份证明；GLM-5.2 不冒充 GLM-5.3，历史 Doubao-pro 不冒充 lite。

## 测量与防泄漏

使用现有八事件定义与证据行协议；三个核心事件为 answer_reveal、reasoning_elicitation、affect_acknowledgement。编码者看到已去掉生成指令和模型元数据的对话、问题与参考解、可见教师回答。生成模型、任务臂、来源编号不进入编码正文；文字风格仍可能暴露身份。旧学生对话/参考解可能由人撰写，但本研究不新增人工标注。

编码者沿用当前 MiniMax-M3、DeepSeek-v4-pro、GLM-5.3，不用历史模型别名发起新调用。请求 temperature=0.0，max_tokens=32768，timeout=660 秒；此预算在新调用前统一冻结，避免把前序研究的 16,384 token 截断问题静默混入本研究。MiniMax 总并发最多 4、Gateway 总并发最多 8。最多三个 pass，每 pass 最多两个请求尝试；只补结构或传输失败，保留全部原始结果。

机械 JSON 恢复仅允许原样返回的完整八事件对象缺最外层一个右花括号，并且错误恰在 EOF：单独记录派生修复，通过原冻结解析器，不改值、不改证据、不计新 API 回答。这是提前声明的档案执行规则，与原 v4 的事后修订明确区分。有效编码一律复用，不按标签或是否一致决定补跑。完整面板不足时停止，不把未知编码记为 0。

## 分析与可证伪解释

1. 公布七配置 × 两指令的三核心事件率及来源 bootstrap 区间，报告非互斥行动（给答案且邀请推理）的联合率。来源等权，两臂始终配对。
2. 对每模型的 pedagogy 减 scaffolding 率差给出来源配对区间，报告 21 个描述性比较。模型间的差异在两臂分别展示，不把题目或回答行当独立重复。
3. 使用固定 5 折来源划分的交叉预测，比较仅指令条件的事件率与指令×模型事件率，采用固定 Jeffreys 平滑 `(positive+0.5)/(n+1)`，没有调参。另用另一指令臂的模型画像预测目标臂，训练时排除目标折全部来源。报告绝对 Brier 和来源损失差。它检验来源留出与指令迁移，不能等同 v3 的预测先于教师生成。
4. 三个单编码者面板单独重复率和损失统计。逐一删除生成配置后报告剩余模型的同一冻结交叉预测损失，不重新拟合该敏感性。报告正类一致性，不用总体一致率掩盖稀有事件。
5. 主要推断是这些选定档案配置、材料及提示条件上的行为差异和迁移边界。来源 bootstrap 固定原交叉拟合概率，不包含拟合不确定性的完全重训练；不以其区间冒充严格的前瞻性假设检验。不额外制造显著性检验家族。

如果自然对话中默认差异大幅消失、发生反转，或只能在同一指令中预测，就收缩论文主张；不能以合成实验更清晰为由删除档案结果。反之，跨来源预测有效也不能证明学习收益、情绪理解、人类人格或内部机制。

## 数据处理与进度边界

原始档案只读。编码请求包含所选公开 benchmark 对话、问题/参考解和模型可见回答，绝不包含 API 密钥、上游学生身份 ID、人类教学评分或隐藏推理。完整载荷及原始响应只保存在忽略目录；公开审计保留哈希、输入选择和失败记录。新的数据来源和发送内容在 launch 审核时明确列出，不沿用“仅合成数据”的旧载荷声明。

该协议、选样、源数据哈希、编码器和分析程序在调用前冻结。长任务后台启动后只检查一次，不持续前台轮询。实验完成之后仍须整合中英文论文并重新进行实质质量评估。
