# 补齐冻结协议中的内容错误敏感性

日期：2026-09-05。正式训练评审仍在运行，确认回答尚未生成。

## 发现的缺口

冻结协议 research/50 第 5 节已经承诺“可核验数学子集与明显内容错误的敏感性”。现有主分析摘要也将 content-error sensitivity 列为单独的未完成要求；原接续程序只完成主要预测与评审、模型删除、训练重采样敏感性，尚未执行这一项。不能仅靠把答案揭示定义为“包括错误结论”就视作这项承诺已完成。

此次补充实现原协议的次要检查，不改三项主要事件、六项主要比较、原始题目、训练画像或确认预测。规则在训练评审中、确认回答生成之前固定；属于有时间披露的补充规定，不能冒称整个项目开始前的预注册。

## 固定范围与测量

两位自动评审 MiniMax-M3、DeepSeek-V4-Pro 检查全部 1,280 条标准角色确认回答。另有 12 条 agent 编写的控制回答，六条包含明确错误、六条不含明确错误，覆盖答案正确／错误、不直接给答案、引用并纠正错误、假设检验提问、学生作答反馈与基础科学／语法。总计首轮 2,584 个评审请求；没有新增导师回答或人工标注。实际 HTTP 重试与结构修复另记。

评审看到学生消息、参考解和原始回答行号，不看到生成模型、条件编号或控制标签。三类判定分别为：发现明确内容错误、未发现明确内容错误、无法确定。未发现错误不等于完全正确；未给答案、简短提示、提问和被正确纠正的引述本身不是错误。明确错误必须有类别及有效原始行证据。错误类别限定为错误最终结论、错误解释步骤、错误的学生作答反馈、其他可核查错误。

控制回答只提供有限诊断证据，没有人类金标准。每位评审在两个类别中都至少匹配 5/6，才达到预定的控制诊断规则。若任一评审未达到，保留全部编码与数值结果，但将按错误筛选的发现限于测量受限的诊断，不用它支持稳健的内容控制结论。即使达标，也不能推出真实回答的全部错误已被发现。不会依据分歧或判定标签重试，结构／完成失败最多增加两轮相同输入修复。

## 数学子集与配对筛选

所有比较使用已经锁定并完成评分的原始预测；不重新拟合或调参。报告来源等权的绝对 Brier 及六种既有比较的描述性差值、来源 bootstrap 区间，不增加主要假设检验或显著性星号。

固定报告五个范围：

1. 全部标准角色确认回答，与原主分析数值核对。
2. 全部八个数学来源、320 条回答，不按结果选择题目。
3. 排除含“两评审均判明确错误”回答的配对单元。
4. 排除含“任一评审判明确错误”回答的配对单元。
5. 排除含“任一评审判明确错误或无法确定”回答的配对单元。

一个配对单元由来源、学生作答状态、情绪线索、重复编号确定，包含五个模型回答。某个回答触发筛选时，整个五模型单元共同排除，保留每项的去留映射与来源、模型覆盖。没有留下足够来源时明确报告无法估计，不填补或恢复有利样本。

筛选依赖生成后的回答，改变了目标分布，即使五模型配对完整，也不是对能力的因果控制。主要结果始终使用全部回答。本补充只覆盖标准角色确认面板，不把它扩写为全部提示干预回答的内容核验。

## 实现、验证与接续

`scripts/personality_content_sensitivity_v3.py` 负责盲化请求、结构审计、全部有效记录复用、内容标志及配对敏感性。`scripts/complete_personality_content_v3.py` 等待现有确认控制进程释放 OS 锁且报告成功，再执行本补充；沿用原 API runner 的共享提供方并发限制。不会启动第二份训练或确认生成。

合成数据演练覆盖全部 1,280 个标准回答位置及 12 个控制位置，串联 2,584 项请求准备、一个模拟传输失败、2,583 项有效记录复用、修复与最终分析。它没有 API 调用，没有读取真实行为标签作为模拟结果，也没有建立真实预测锁。另检查证据行、身份信息盲化、部署与输入哈希、无法确定的保留、五模型共同筛选及来源等权。代码演练是程序证据，不是内容判断准确率。

补充规则与依赖哈希记录在 `prospective_formal/content_sensitivity_policy.json`。最终完成还必须检查 `content_sensitivity/analysis/summary.json`、控制诊断、内容覆盖、保留样本映射和全部子集结果；进程存活或 API 返回成功都不足以证明完成。
