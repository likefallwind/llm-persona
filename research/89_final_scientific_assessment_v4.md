# 研究内容与完整文稿的最终质量评估

2026-09-08。本评估针对 `paper/educational_personality_v4` 当前整合稿，取代 research/70、76 在当时记录的未完成判断，不改写旧检查点。判断对象是能否支撑一篇详实、可审查的顶会投稿论文，不是预测某次评审必然录用。

## 判断

**目前的内容和完整稿已足以支撑一篇详实的顶会投稿论文。** 理由是研究已给出围绕原始人格问题、可被反驳且经过实际检验的结果组合：默认倾向可预测，但学生状态画像的迁移更脆弱；明确教学指令进一步限制默认差异的表达。它同时报告支持与失败，不靠增强措辞或把复杂预测器总说成更好来形成结论。

研究回答的是指定部署的教学行为画像是否反复出现、能跨哪些输入变化；没有证明人类式心理人格、内部情绪理解或教育独有的人格因子。这一范围来自可观察生成内容与实验所能识别的对象，而不是用一个更容易成功的应用任务替代用户的人格问题。教学路由、学习收益及人类偏好评价不再争夺主线。

## 为什么两个缺失编码不需要伪装成完成

原覆盖门槛是为了避免未知多数影响分析。现在承认该门槛未通过，保留失败退出记录；通过另一条公开说明的证据路径判断终点是否可识别。两条回答的其他两票在全部八事件一致，第三票任取 0 或 1 都不改变多数。审查程序从实际票重新枚举全部 28,672 个回答—事件多数，16 个不完整三票事件均有唯一结果。

三位单编码者的完整面板也没有以小样本结果代替：保留完整 256 来源及原五折，逐事件枚举 DeepSeek 两个未知标签的四种取值，涵盖六个缺失主要标签全部 64 种联合取值。脚手架揭示／邀请增益始终为正、跨指令增益始终为负。明确探问下的微小邀请增益在某编码者下为负，因此未写成普遍正向。原编码缺失、事后修订和可识别终点是不同事实。

## 仍需保留的审稿风险

1. **人格解释较窄。** 三个事件不是潜在人格分类。论文以问题形式提出教育人格，以可预测动作画像作有边界的回答。
2. **材料有限。** 32 个新问题、固定且与来源嵌套的表达对、以两句话语为主的档案，不代表所有语言或长程教学。更广域复制属于后续外推，当前结论保持有限。
3. **自动测量有共享偏差。** 一致率和证据定位不是语义真值。档案承接正例一致率约 65%–67%，自然内容错误正例一致率 18.5%，相应主张已经收缩。
4. **条件区间不覆盖全部不确定性。** 档案 bootstrap 固定拟合概率，未覆盖全部重拟合和训练折依赖；事后诊断不提升为独立确认性检验。
5. **新颖性有竞争。** 最近前作已覆盖行为画像和语境敏感性。本文价值取决于结果组合与解释，不以样本数、审核数量或“人格”命名本身作创新。

这些限制不要求新增人工标注或无边界追加实验；它们明确成稿可支持的命题。若后来要主张真实课堂有效性、内部人格机制或普适心理类型，需要另立研究目标，不能从当前结果直接推出。
