# 教育人格独立验证：测量试验协议

日期：2026-09-05。本文件记录新测量试验，**不是正式人格确认协议**。正式数据、主要终点和分析必须在此试验完成并解决测量问题后另行冻结。

## 目的与材料

使用原创合成教育情境测量具体行为，检查回答重复性、编码可靠性和表达机会。四个试验模板分别涉及线性方程、分数减法、密度判断和因果论证；每题交叉设置学习进度（错误的早期尝试/正确的后期中间步骤）和情绪表述（平静/受挫），得到16个情境。每个模型在每个情境独立请求两次，共160个生成请求。所有模板及其改数值版本永久留在开发阶段，不进入正式确认集。

系统消息完全一致：`You are a tutor. Respond to the student's last message.` 不强制问题列表、指定教学动作或要求人格自报告。temperature=0.7，max_tokens=8192，非流式接口。没有供应商 seed 保证；两次独立请求不保证独立随机数流。记录可见回答、使用量、时间、结束原因、请求及返回模型名和完整输入哈希。未正常结束或没有可见回答的请求不算完成。

这轮学习进度与答案正确性有意捆绑，用于产生可观察行为机会；不能用其估计纯进度或纯正确性因果效应。四个模板及两个重复也不能支撑跨领域人格结论。

输入冻结文件：`artifacts/educational_personality_v2/prospective_pilot/freeze.json`。制备脚本在已存在输入与重新生成结果不同时报错，禁止覆盖冻结材料。

## 模型身份与调用

请求面板为 MiniMax-M3、MiniMax-M2.7、deepseek-v4-pro、doubao-seed-2.0-lite 和 glm-5.2。前两者使用 MiniMax 官方，其余使用仓库既有 Gateway；官方总并发不超过4，Gateway不超过8。运行器持有两种提供方的排他锁，并按模型分批调用，其他使用本运行器的试验不能叠加并发。

**版本审计发现：** 在公开算术连通性检查中，本地 Gateway 的 `glm-5.2 -> glm-5.2` 路由实际收到上游 `model=glm-5.3`。所以该请求配置不代表新生成了 GLM-5.2 数据。本试验保留请求别名作为 provenance，统计与图表必须显示实际返回的 GLM-5.3；它与旧 GLM-5.2 的数据分开。逐条检查返回版本，如果同一请求配置出现多个返回版本，不得自动混合统计。正式实验将重新核验并显式请求实际版本。其他四模型在 smoke 中请求名与返回名一致。

所有调用仅含原创合成材料和它们产生的回答，不发送已有学生对话。响应与日志留在被 Git 忽略的运行目录。模型按块运行是本轮限制，正式试验应交错模型、情境和重复的时间安排，以降低服务时变造成的混淆。

## 测量与诊断

`data/educational_personality_measurement_v2.json` 冻结8个可共现的二元行为事件：答案揭示、展开解释、引导推理、提供学习者选择、承接情绪、限定知识断言、询问缺失事实、超出证据的能力归因。它们是事件编码，尚不是8个人格维度；最后一项也不作道德或教学质量评判。

每个正例必须引用可见回答中的逐字证据；负例必须无引用。不向评审提供生成模型名或预期人格。MiniMax-M3、GLM请求配置（实际版本另审）和DeepSeek-V4-Pro三位评审独立编码；不读取隐藏推理。

另有16个由研究 agent 编写的诊断锚点，涵盖礼貌词、真追问与自问自答、选择空间、具体情绪承接、不充分证据和缺失事实。预期标签与评审消息分开保存。锚点是明确规则的实现检查，**不是人工金标，也不能替代自然回答上的构念效度检验**。锚点及其预期标签先于对应评审调用冻结。

检查所有事件的结构与引用有效率、逐评审锚点分歧、自然回答的正负例比例、逐对正/负一致性、三评审全体一致性，以及两次生成的行为一致性。全为0产生的高一致性不算有效识别；没有表达机会的事件不能据此判定人格不存在。评审和生成模型重合，须在正式分析中报告去掉同模型/同家族评审的结果。

任何锚点分歧或自然回答测量问题均保留原结果，解释并进行新版本测量，不能覆盖旧量表后宣称首次通过。试验结果可用于决定测量和样本量，但所有利用它作出的决定必须在独立正式数据生成前冻结。

### 首轮锚点之后的测量修订

首轮48/48请求均正常完成且引用结构有效，但384个事件编码中有5个与 agent 编写的预期标签不一致，集中于两个锚点：三评审均把间接建议“你可以试着除以2”判为引导推理；另有两评审把同一个计算结果的两次表述算成两个解释步骤。

前一项体现预期标签和定义边界的问题，不能归咎于三位评审全部出错。新版本明确：未替学生完成的步骤邀请包含疑问、祈使和间接建议，相应修改该诊断锚点的预期标签。后一项明确要求不同的实质运算或推断步骤，同一结果的复述不增加步骤。

新量表为 `data/educational_personality_measurement_v2_1.json`；诊断材料为 `data/educational_personality_anchors_v2_1.jsonl`，含16个保留/修订锚点和16个新增措辞锚点，新增内容是诊断扩展，不是独立人格确认。原量表、预期标签和48次结果全部保留。自然生成回答的首个评审清单曾按原量表制备，但**未调用**；澄清后的自然回答评审使用单独目录 `judge/v2_1`，不混合两版本评分。

## 正式确认仍需要的设计

正式情境使用独立内容和解题结构，覆盖比这四题更广的教育活动。区分输入中的知识状态、请求和证据充分性，并把无关措辞与明确教学指令设为不同干预。选择主要行为终点时不要求预设数量的人格维度成立。

主要证据应包括：同情境重复的一致性；按模板/来源留出的行为预测，对比总体、模型均值、情境、任务、长度/风格及能力基线；中性改写下的保持和教学指令下的位移。能力和风格若来自目标回答，属于同时测量的竞争解释，不能伪装成事前预测器。不能使用测试项全模型评分的中心化数值声称能从输入直接预测绝对行为。

本轮只补充测量与可执行性证据。其结果好坏都不改变“研究教育人格”的目标，也不会把任务缩为提示工程、教学路由或学习效果研究。
