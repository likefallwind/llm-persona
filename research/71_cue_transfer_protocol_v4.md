# 教育行为画像能否跨表达方式迁移：v4 补充实验

本方案在看到 v3 全部结果后提出，目的是区分可迁移的行为规律与固定措辞触发。它是新的、有事前预测锁的补充实验，不是原始预注册的一部分。v3 数据、程序、失败记录、预测和结论均不覆盖。

## 核心问题与可能推翻主张的结果

模型默认的答案提供、推理邀请差异，以及条件性的情绪/困难承认差异，能否由原 v3 训练集拟合的预测器直接预测新的表达？如果仅原句有效，跨表达主张必须收缩；如果显式同义句有效而隐含线索无效，应报告表达方式的适用边界；如果他人情绪也改变回应，则“针对当前学生状态的响应”解释需要进一步限定。任何方向的结果都保留，不以显著性、模型排序或论文好看程度追加样本。

## 材料与独立性

复用 v3 的 32 个确认题目、32 个 source_family、4 个领域，每领域 8 题。这些不是新题目，也不把它们和 v3 合并当作 64 个独立来源。新生成与 v3 训练来源无重叠；本次直接检验表达方式迁移，档案自然对话迁移另设研究。

每题保持题干、错误尝试/正确未完成步骤、教师参考答案和中性 tutor system 原文不变。交叉五个当前部署、两个工作状态、两个请求重复：

1. canonical：v3 原版 calm/frustrated 两句，作为同期对照。
2. explicit：避开 calm/frustrated 的直接情绪同义表达，两极各一句。
3. implicit：通过行为或话语暗示的两极，各一句，不声称它们与显式情绪在所有语义上等价。
4. peer_control：学生始终明确 calm，只将做另一题的同学所说的话在 calm/frustrated 间替换。预测器的 affect 输入始终为 calm；另存 cue_pole。

explicit、implicit 各有四对固定措辞。每领域题目按固定 SHA-256 排序，分别以 index modulo 4 和 (index+1) modulo 4 配置一个表达对。每对覆盖每领域两题、合计八题；同一题全部模型、工作状态与重复使用同一对措辞。这是预算受限的平衡嵌套设计，不是每题与四对表达全交叉。词句效应与题目不能完全分离，不对任意未见表达总体作推断。

每个 register 有 1,280 个回答；合计 512 情境、5,120 个教师回答。每个回答使用原先三位部署编码，共 15,360 个有效编码目标。重复是两个 API 请求，不保证独立随机数流。

## 冻结预测与主要检验

直接复用 v3 `locked_predictions/predictions.csv`：按领域、工作状态、学生状态、模型匹配其概率，验证同一特征元组下所有 v3 源题/重复概率一致。新措辞不进入特征，不拟合、不重新选择正则化、不使用 v3 确认标签。保存每个新请求的预测和旧预测文件哈希，所有锁早于本次第一个生成请求。

三个原事件定义和八事件编码协议保持不变。每个新 register（explicit、implicit）的主要比较为：

- answer_reveal：context 的 Brier loss 减 default_profile 的 Brier loss；
- reasoning_elicitation：context 减 default_profile；
- affect_acknowledgement：domain_profile 减 conditional_profile。

合计六个单侧检验，原假设为源题平均改进不大于零，Holm 控制该六项 family-wise error rate 0.05。每题先等权平均模型、工作状态、线索两极和重复，再做 32 个源题的配对 t 检验。报告原始 p、Holm p、Brier 绝对水平、绝对改进及按领域分层的源题 bootstrap 95% 区间（10,000 次，固定种子 20260907）。不宣称受控随机抽样总体；区间描述此材料抽样假设下的不确定性。固定样本量不保证对小交互的功效；不把不显著解释成无差异。

同期 canonical 单独报告，检查部署/时间漂移；不会因为原句结果不理想而删除模型、重拟合预测或重跑直到复现。canonical、peer_control 不加入六项主要检验，所有四种 baseline、三事件和 register 均完整发布。主要显著不意味着跨措辞等价或人格已经验证。

## 竞争解释与稳健性

- 比较 explicit/implicit 与同期 canonical 的源题配对预测改进差异及区间，报告绝对校准误差，不只报告模型排序。
- 在 peer_control 内，学生自身始终 calm，对比同学 frustrated 与 calm 的事件率。与 canonical 的学生本人两极差异并列，不能将两种载体差异当作严格的所有权交互因果效应。没有发现 peer 效应不证明模型理解情绪归属。
- 三事件分别按模型、工作状态、cue_pole、register 公布事件率、两次请求的正/负及总体一致率。
- 主要预测比较同时给出三个单编码者面板；保留全部编码，不按同意程度筛选答案。逐一删除生成模型后，用同一冻结预测报告剩余模型的改进，明确这不是重新拟合的 leave-model-out。
- explicit/implicit 各四个措辞对的描述性结果单列，但只有八个源题/对，不进行新的显著性筛选。
- 旧词汇 calm/frustrated 在新表达正文中必须不存在；工作文本、题干、system 的字节与旧材料一致。词汇隔离只验证材料，不代替行为结果。

## 执行、缺失与停止规则

使用原请求运行器，MiniMax 总并发最多 4，Gateway 总并发最多 8。运行前检查其他任务，避免叠加。教师 temperature=0.7、max_tokens=8192；编码 temperature=0.0、max_tokens=16384；timeout=660 秒。固定部署为 MiniMax-M3、MiniMax-M2.7、glm-5.3、deepseek-v4-pro、doubao-seed-2.0-lite；编码者为 M3、DeepSeek、GLM-5.3。返回 alias 必须逐条匹配，不将 alias 当作不可变权重证明。

每阶段最多三个执行 pass，每 pass 请求最多两次传输/完整性尝试。所有有效回答/有效编码一律复用；编码只能因结构、证据行、完整性问题补跑，不能因标签、不同意或结果方向补跑。所有原始失败记录保留。本方案不自动加大 token budget；用尽后停止并记录缺口，另作有日期的技术修订才能改变策略，不能默默替换结果。配对不完整时不出主要完整面板结论。

程序、材料、分析规则、依赖和预测 hash 在调用前冻结。可恢复控制器持有专用锁、保存步骤状态和日志；研究运行完成不会设置论文质量目标为完成。

## 与档案和论文的关系

这个补充实验解决固定措辞解释，不单独解决自然对话/复杂任务外部效度或构念广度。后续仍需恢复档案题目与 harness，明确历史输入重建证据等级，检验自然 tutor 回答；也需要把新增证据放到与 CIMA、TRAIT、TutorPersonas 和 BMA 的具体差异中重新评估创新性。无新人工标注；agent 编码、相互一致或语义线索材料均不是人类心理真值。
