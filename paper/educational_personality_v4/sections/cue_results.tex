\subsection{Default Gains Survive New Expressions; the State Gain Does Not (RQ2)}
\label{sec:cue-results}

The extension yields all 5,120 answers and 15,360 usable codes. One code needs a
disclosed one-character structural recovery; all three primary majority labels
are unchanged under either possible value of that missing vote
(Appendix~\ref{app:cue-transfer}). Pairwise positive coder agreement is
99.25--99.41\% for revelation, 90.68--92.34\% for elicitation, and
94.89--95.51\% for acknowledgement.

Frozen default profiles retain substantial gains under both new expression
arms (Table~\ref{tab:cue-primary}). In contrast, the acknowledgement state
profile does not retain its incremental gain: -0.00366 for explicit synonyms
and -0.00628 for implicit cues. The contemporary original-wording gain is
+0.01248 [0.00888, 0.01624]. Paired new-minus-contemporary gain differences are
-0.01614 [-0.02254, -0.00990] and -0.01876 [-0.02384, -0.01358], respectively.
These secondary paired contrasts weaken a simple explanation in which all
profiles cease working across deployments at the later observation time.
Figure~\ref{fig:expression-transfer} separates the two transfer tests.

All three individual-coder panels have positive contemporary and negative
new-expression acknowledgement state-gain estimates. Both new-expression point
estimates also remain negative in all five generator-deletion panels; some
intervals include zero. These are sensitivities of the same responses, not
independent replications. The failure concerns transported conditional
probabilities: models still exhibit acknowledgement differences between cue
poles, and the implicit arm changes more than affect wording alone.

\paragraph{Alternative explanations.}
The explicit arm loses relative advantage while slightly improving its own
conditional loss; the implicit arm also worsens absolute conditional loss.
Post-result accounting and source-held-out calibration constrain simple
prevalence-shift and logistic-calibration explanations, without excluding
richer semantic or modeling alternatives
(Appendices~\ref{app:cue-diagnosis}--\ref{app:cue-calibration}).

In the secondary peer control, social context changes acknowledgement of a
fixed current-student state. Selected examples show that this can happen with
correct emotion attribution; the contrast alone does not identify misattribution
(Appendix~\ref{app:cue-transfer}).
